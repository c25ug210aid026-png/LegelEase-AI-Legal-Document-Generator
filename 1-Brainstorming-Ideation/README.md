# 1. Brainstorming & Ideation Phase

### Project Title: LegalEase - AI Legal Document Generator

**Problem Statement:**
General people ku legal documents like Rental Agreement, NDA, Employment Letter create panna theriyathu. Lawyer kitta pona Rs.500 - Rs.2000 varikum charge pannuvanga. Time waste aagum.

**Proposed Solution:**
Oru AI website create pannalam. User enna document venum, details kudutha AI automatic ah professional legal document generate panni PDF ah download panna mudiyum.

**Key Features:**
1. User friendly form - name, address, date maari details keka
2. Multiple templates - Rental, NDA, Service Agreement
3. AI powered content generation using Gemini API
4. Instant PDF download
5. Secure and confidential

**Target Users:** Students, Startups, House Owners, Small Business
